# Система управления сетью кофеен

Учебный проект по учебной практике представляет собой оконное WPF-приложение для автоматизации управления сетью кофеен с подключением к локальной базе данных.

## Основной функционал
* **Авторизация и регистрация**: Разграничение прав доступа (Пользователь / Администратор), хеширование паролей (SHA1), защита от брутфорса с помощью капчи.
* **Страница Пользователя**: Каталог товаров с поиском, сортировкой и фильтрацией. Просмотр личной истории заказов.
* **Панель Администратора**: 
  * Полный CRUD (создание, чтение, обновление, удаление) для всех таблиц БД (Пользователи, Товары, Заказы, Кофейни).
  * Построение аналитических диаграмм (круговая, столбчатая).
  * Экспорт отчетов в Microsoft Word (.docx, .pdf) и Microsoft Excel (.xlsx).
* **Интерфейс**: Динамическая смена светлой и темной темы (с сохранением выбора). Использование глобальных словарей стилей (ResourceDictionary). Заголовок окна меняется в зависимости от открытой страницы.
* **Безопасность**: Каскадное удаление данных в БД, подтверждение выхода из приложения и удаления записей.
* **Смена пароля**: Валидация сложности нового пароля и проверка старого.

## Стек технологий
* **Язык**: C#
* **Платформа**: WPF (.NET Framework)
* **База данных**: MS SQL Server (SSMS)
* **ORM**: Entity Framework (подход Database First)

## Структура репозитория
* `db/` — каталог с SQL-скриптами.
  * `schema.sql` — скрипт создания базы данных и таблиц со всеми связями и ограничениями.
* `res/` — каталог для ресурсов приложения (иконки, изображения).
* `ISIP223_Kuznetsov_coffeeShop/` — исходный код WPF-приложения (файлы `.cs` и `.xaml`).
